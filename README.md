# CreatorIQ Backend

Backend API for the Creator Analytics & Content Performance Dashboard.

## Technologies

- FastAPI
- PostgreSQL
- SQLAlchemy
- Pydantic
- JWT
- Bcrypt

## Authentication

The application implements:

- User registration
- Password hashing
- Password verification
- JWT authentication
- Protected endpoints
- Token expiration
- Current-user authentication
